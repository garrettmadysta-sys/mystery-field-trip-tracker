## How to Update Your GitHub Site

1. Go to: https://github.com/garrettmadysta-sys/mystery-field-trip-tracker
2. Click **Add file** → **Upload files**
3. Drag ALL these files into the upload area:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.webmanifest`
   - `service-worker.js`
   - Keep your existing `icon-192.png` and `icon-512.png`
4. Click **Commit changes**
5. Wait 1-2 minutes for GitHub Pages to rebuild

## Clear Old Cache on iPad
If Eli's iPad still shows the old version:
1. Open Safari → Settings → Safari → Advanced → Website Data
2. Find the github.io entry → Delete
3. Reload the site
4. Re-add to Home Screen if needed

- 20 points per passed AR test

- 10 bonus points for hitting daily target
